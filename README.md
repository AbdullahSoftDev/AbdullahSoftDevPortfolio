## ✨ Overview

This repository contains the source code for a developer portfolio built with **React, TypeScript, Tailwind CSS, and TanStack Start**. Use it to explore the implementation of a modern web interface and the components that power the portfolio experience.

## 🧰 Tech Stack

| Technology | Role |
|---|---|
| React | Component-driven user interface |
| TypeScript | Typed application code |
| TanStack Start | Application framework and routing |
| Tailwind CSS | Utility-first styling |

## 🚀 Getting Started

### Prerequisites

- Node.js (current LTS recommended)
- npm

### Run locally

```bash
git clone https://github.com/AbdullahSoftDev/AbdullahSoftDevPortfolio.git
cd AbdullahSoftDevPortfolio
npm install
npm run dev
```

Use the local URL printed by the development server to preview the application.
